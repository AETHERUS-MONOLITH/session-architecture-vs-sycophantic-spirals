What each condition changes

  • C0
    Continuous

    No break. Baseline.

  • C0+R
    Continuous + review

    Reference cell (decided 30 Oct). As C0, plus the review instruction of C2 after turns 10, 20 and 30, inside the one context. Separates the review instruction from the cut.

  • C1
    Self-summary

    Break; same model writes a free summary; new context continues. Break, fresh instance and self-written summary come together; C1 does not isolate the break on its own.

  • C1+R
    Self-summary + review

    Reference cell (decided 3 Nov). As C1, plus the review step of C2 at every cut. Separates the review from the report format.

  • C2
    Fresh review

    Break; structured, status-tagged report; fresh instance reviews before continuing.

  • C2−R
    Report, no review

    Optional extension (3 Nov). As C2, without the review mandate of the next instance. How to write a structured report without an implicit review is still open.

  • C3
    Independent report

    A separate instance writes the report from the transcript. Extension only.

  • C4
    Cross-model

    As C2, but the next session runs on a different model family. Reduces dependence on a single model family's learned biases.
